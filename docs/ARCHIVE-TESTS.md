# 可选历史证据测试

默认 `npm test` 执行核心测试，排除 `tests/release-evidence-audit-2.6.test.mjs`。后者验证历史报告审计器的错误拒绝行为，不是应用启动必需测试；依赖8份原始报告共72,597,018字节。

原件带当时作者的绝对保存回执路径，不在公开源码仓库复制，也不为发布改写历史哈希。需要该测试时，取得对应完整证据材料，将 `archive-test-inputs.json` 列出的原件放入本机 `reports`，再运行：

```sh
npm run test:archive
```

缺文件时退出2并列相对路径。它不会联网下载、不会启动浏览器，也不会补造占位报告。私有原件不得因本地恢复而加入Git；`reports`已忽略。

完整历史离线门禁还有自己的工具/原件依赖，未在本精简仓库中声称可以直接重跑。发布说明应提供经审计证据资产及SHA；链接未提供时，说明材料尚未公开，不应宣称读者已能完整复核。
