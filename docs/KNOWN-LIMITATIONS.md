# 已知限制

- 真实百度SDK强制WebGL上下文丢失后曾触发整页重载；六故障恢复协议没有通过。不能以新页面启动代替原地图实例恢复。
- 工作负载以合成点、折线和矩形为主；没有真实工业设备消息上游和任意GeoJSON支持。
- 位置更新将同ID已绑定顶点设置为指定坐标，不是几何整体平移；后续同ID追加不继承此前位置/颜色更新，删除状态会继续生效。
- 拾取语义是最近顶点，且忽略删除/alpha0。它不是点落在线段或面内的完整空间选择工具。
- 上传ACK确认GL调用已提交；rAF回调、GPU区间和实际显示帧率分别解释。
- 固定2048在某些快速源材料的总完成时间慢于其他策略。hybrid可能更快但后续整批确认更稀，仍是候选。
- 动态bounds和神经成本顾问未证实稳定净收益，默认关闭相关实验优化。神经异常检测演示有较高误报，完整负结果在ml材料中保留。
- 当前核心测试使用Node与mock/协议环境。其通过不等于浏览器、GPU、SDK或跨设备性能通过。
