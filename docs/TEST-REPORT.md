## 本轮组合实验

- 两套质量材料合计 **246个 harness 断言、72次完整 RGBA 对照**。包含预期失败和取消的正确处理，不能解读为每个业务 run 都完成。
- **54次性能加载**：本地沙盒30次，真实百度 SDK 快流12次、限速供给12次。所有业务数据均为合成材料，未调用地点检索。
- 当前默认、hybrid、固定8192、hybridBounds均参加；reference只在本地性能实验中参加。质量阶段五组常规材料加四组跨页材料，范围并不完全相同。

详见[方案、逐场景结果与限制](CHAIN-COMBINATIONS-RESULTS-2.6.md)以及[公开衍生 JSON 摘要](../reports/chain-combinations-public-summary-2.6.json)。摘要保存原始报告 SHA、字节数和逐轮结果，省略私人路径与大型原始数组；它不是原始实验回执。复现入口见[浏览器复现](BROWSER-REPRODUCTION.md)。

这些结果支持保留固定2048作为通用默认。hybrid在本机百度SDK百万快流材料中完成耗时中位数从2611.4降到2078.8ms，约减少20.4%；限速供给和本地沙盒没有证明同样收益。动态边界候选增加维护CPU和摘要内存，没有采用为默认。

## 身份与解释边界

组合实验原件保留其实际源码身份：legacy `7f31f24b6beae2fe2b52960898edfef18d1c3ababb9c3846a8c77f51077e23cc`、runtime-v2 `fcc172a190aab5292ab81e39c2e2af9121fd10c3ff63fcc8e98cababab46bfbe`。本公开副本只改了 `package.json` 的核心/归档测试入口，以及 `public/ai/NOTICE.txt` 的来源相对路径；它们改变完整runtime指纹，算法和服务器实现未改。不能将旧runtime指纹写成新副本当前指纹。

594项与11项检查是在公开副本测试入口拆分后执行；NOTICE路径更正随后进行，属于静态来源说明修正。初次准备记录在[创建时点清单](repository-preparation.json)，该记录没有后填成测试结果。后续复现报告由工具记录实际文件指纹。

当前链路质量工具核CPU几何槽位并做实际RGBA读回，没有实现独立GPU上传缓冲镜像。像素参照复用当前着色器，不能证明着色器自身无误。首次提交、ACK、CPU更新时间和帧间隔各有独立含义，不能换算成整张百度地图FPS；三次材料重复也不是统计显著性证明。

历史研究已有独立的612项Node、149次原生RGBA和普通SDK等证据，但本精简仓库未分发全部原件，也不将那些数字算成本次新执行。**真实SDK强制context loss后触发整页reload的问题仍未解决**；普通SDK加载通过不代表context恢复通过。更多边界见[已知限制](KNOWN-LIMITATIONS.md)。
